# WTWR (What to Wear?): Back End

The back-end project is focused on creating a server for the WTWR application.
What the Back End Does:

1. Stores Data — It keeps track of clothing items (like jackets, boots, etc.) in a database or file.
2. Handles Requests — When the front end (the website) asks for data, the back end responds with the right information.
3. Manages Routes — It defines what happens when different URLs are visited (e.g., /items to get all clothing items).
4. Performs CRUD Operations — It allows you to:
   - Create new clothing items
   - Read existing ones
   - Update them
   - Delete them

Think of it like a restaurant kitchen 🍽️ — the customer (front end) places an order, and the kitchen (back end) prepares and delivers it!

## Running the Project

`npm run start` — to launch the server

`npm run dev` — to launch the server with the hot reload feature
